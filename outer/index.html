口径与陷阱

各家缓存机制根本不同，别横向硬比
  • OpenAI：写入 30m = 1.25× 输入，12h = 2.5×，读取 0.05–0.1×。写入费顶替输入价，不是叠加。
  • Anthropic：写入 5m = 1.25×，1h = 2×，读取 0.1×（Opus 5.5 / Sonnet 5.5 为 0.05×，Fable 5.1 为 0.025×）。
  • Kimi：写入费与输入价完全相同（5min=1×、1h=2×），读取 0.1×。所以「写不写缓存」成本一样，差别在后续读取。
  • DeepSeek：磁盘缓存全自动，无写入费，命中价仅为输入价的 2%。
  • GLM：缓存存储限时免费，也无写入费，命中价约输入的 20–25%。
容易踩的坑
  • DeepSeek v4-pro 自 2026-09-14 起请求已全部路由到 V4.1-Flash 并按 Flash 价计费，表内已按生效价计算；其目录价（$0.66/$1.98）仅作参考。
  • DeepSeek 有高峰时段：周一至周五 UTC 01–04、06–10（北京 09–12、14–18），全档翻倍。
  • Anthropic Fast 模式只有 Opus 5.5 / Opus 5 / Opus 4.8 支持，其余模型点了也不生效。
  • Anthropic Haiku 5.5 按 prompt 长度分档：超过 100K token 整单跳到高价档（输入 $0.10→$0.50）。
  • Anthropic 4.7 起换新 tokenizer，同样文本 token 数多约 30%——单价相同不代表实际成本相同。
  • OpenAI 输入超 272K 后输入侧各项 ×2、输出 ×1.5；Anthropic 则 1M 上下文全窗口同价。
